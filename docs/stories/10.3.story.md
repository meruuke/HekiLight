## User Story

As a player who wants to manage keybind slot overrides, I want a dedicated "Keybind Overrides" section in the Settings panel — at the same level as Appearance, Display, and Ignored Spells — so I can find and use this feature without looking inside an unrelated section.

## Background

Story 10.2 embedded the slot picker and override list inside the "Ignored Spells" collapsible section, reusing its spell dropdown. In-game validation revealed that this is not discoverable: players who want to pin a keybind have no reason to expand "Ignored Spells". The feature deserves its own top-level section, consistent with how every other HekiLight preference is presented.

Story 10.2 remains valid as the data layer and slash-command interface (`dbChar.keybindOverrides`, `/hkl kb pin/clear/list`). This story replaces only the UI container.

### What changes

- A new `MakeSection(L["Keybind Overrides"])` section is appended to the settings panel after "Ignored Spells", using the same header/body/expand pattern as all other sections.
- The section gets its **own** spell dropdown (identical population logic to `ignoreDD` — live from `C_AssistedCombat.GetRotationSpells()`), its own slot picker row, and its own override list.
- The Story 10.2 additions to `ignoreSec` are **removed**: `slotDD`, `pinBtn`, `slotHintLabel`, `overrideRowPool`, `overrideEmptyLabel`, `overrideListSepLabel`, the `RefreshOverrideList` call from the expansion handler, and the `slotShift`/`overrideCount` height logic added to `RefreshIgnoreList`.
- `RefreshIgnoreList` reverts to its pre-10.2 simplicity (no `slotShift`, no override count in height).

### New section layout

```
[Keybind Overrides]                                     +
──────────────────────────────────────────────────────
  Pin the bar slot HekiLight reads for a spell's keybind.
  [kbSpellDD: Select a rotation spell...]  [— no action btn —]
  [kbSlotDD: Select a bar slot...]         [Pin keybind]    ← hidden only when spell has 0 bar slots
  [icon] Spell Name [spellID]  Slot N → Key              [Clear]
  No keybind overrides set.
```

## Acceptance Criteria

- [ ] **AC1 — New section exists:** A "Keybind Overrides" collapsible section appears in the Settings panel after "Ignored Spells", using `MakeSection(L["Keybind Overrides"])`. It starts collapsed. `Settings.RegisterCanvasLayoutSubcategory` is NOT called.
- [ ] **AC2 — Section has its own spell dropdown:** `kbSpellDD` is populated live from `C_AssistedCombat.GetRotationSpells()` (same logic as `ignoreDD`), showing only `IsPlayerSpell` entries. Ignored spells are shown greyed-out and disabled (they can still have keybind overrides pinned via slash command, but the UI does not surface them since they aren't visible in the overlay anyway).
- [ ] **AC3 — Slot picker show/hide:** Selecting a spell in `kbSpellDD` counts non-RA bar slots via `FindSpellActionButtons` (pcall-guarded). ≥1 slot → shows `kbSlotDD` and `kbPinBtn`. 0 slots → hides both, shows `kbHintLabel` ("Spell not on any action bar — keybind cannot be pinned."). Default state (no spell selected) → slot picker hidden.
- [ ] **AC4 — Pin keybind button:** `kbPinBtn` sets `dbChar.keybindOverrides[selectedKbSpellID] = selectedKbSlotID`, prints confirmation, calls `RefreshKbOverrideList()`, resets selection state.
- [ ] **AC5 — Override list rendered:** Each override entry shows: 20×20 spell icon, spell name + `[spellID]`, `Slot N → Key` (or `(unbound)`), and a "Clear" button. Empty state: `No keybind overrides set.` label.
- [ ] **AC6 — Clear button removes override:** Removes `dbChar.keybindOverrides[sid]`, resets slot picker if that spell is currently selected, calls `RefreshKbOverrideList()`.
- [ ] **AC7 — Section expansion refreshes list:** `kbSec.header:SetScript("OnClick", ...)` calls `RefreshKbOverrideList()` on expand (mirrors the `ignoreSec` expansion handler pattern).
- [ ] **AC8 — Story 10.2 ignoreSec additions removed:** `slotDD`, `pinBtn`, `slotHintLabel`, `overrideRowPool`, `overrideEmptyLabel`, `overrideListSepLabel` are removed from the `ignoreSec` block. `RefreshIgnoreList` reverts to its pre-10.2 form (no `slotShift`, no override height contribution). `RefreshOverrideList` forward declaration and all references to it removed from `ignoreSec`.
- [ ] **AC9 — No taint:** All frames created at ADDON_LOADED inside `BuildSettingsPanel`. All `C_ActionBar.*` calls pcall-guarded. No protected frame ancestry.
- [ ] **AC10 — In-game verification:** Settings panel opens, "Keybind Overrides" section visible after "Ignored Spells". Expanding it shows the spell dropdown. Selecting a spell with ≥2 slots reveals the slot picker. Pinning updates the override list. Clearing removes the entry. "Ignored Spells" section unchanged.

## Dev Notes

**File:** `HekiLight.lua` — all changes within `BuildSettingsPanel`

**Key line anchors (approximate, verify before editing):**
- `local ignoreSec, ignoreBody = MakeSection(...)`: ~line 1074 — `kbSec` goes after the entire `ignoreSec` block
- `ignoreSec` block ends at the `ignoreSec.header:SetScript("OnClick", ...)` call (~line 1417)
- `LayoutSections()` final call: ~line 1479 — `kbSec` must be inserted before this

**`MakeSection` creates and auto-appends to `sectionList`** — just calling it in order is sufficient; `LayoutSections()` stacks them top-to-bottom.

**Height formula for `kbBody`:**
```lua
local slotPickerShift = (kbSlotDD and kbSlotDD:IsShown()) and 60 or 0  -- 30 for desc + 30 for slot row
local overrideCount = 0
for _ in pairs(dbChar.keybindOverrides) do overrideCount = overrideCount + 1 end
kbBody:SetHeight(90 + slotPickerShift + math.max(overrideCount, 1) * 30)
```

**Slot picker base Y offsets inside `kbBody`:**
- Description label: TOPLEFT(10, -10)
- `kbSpellDD`: TOPLEFT(-2, -26) (same -2 alignment trick as `ignoreDD`)
- `kbSlotDD` row: TOPLEFT(-2, -56) — hidden by default
- Override rows base: `-90` (below the two dropdown rows + padding)

**`ignoreDD` `info.func` cleanup** — after removing Story 10.2 additions, it reverts to just:
```lua
info.func = function()
    selectedIgnoreSpellID = capturedSid
    UIDropDownMenu_SetText(ignoreDD, capturedName .. " [" .. capturedSid .. "]")
end
```

**Testing (in-game only):**
- `/reload` → Settings panel → verify "Keybind Overrides" appears after "Ignored Spells"
- Expand section → verify spell dropdown populated
- Select spell with 0 bar slots → slot picker hidden, hint label shown
- Select spell with 1 slot → slot picker shown with that one slot listed
- Select spell with ≥2 slots → slot picker shown, all slots listed with keys
- Pin → override row appears, overlay updates on next tick
- Clear → row removed, overlay reverts
- Expand "Ignored Spells" → verify slot picker row gone, no override sub-list
